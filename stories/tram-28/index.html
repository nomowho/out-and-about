GUIDE· LISBOA2024.02.18

里斯本 28 號電車怎麼坐？從 Martim Moniz 上車，一路爬過阿法瑪、主教座堂與太陽門觀景台

28 號黃色電車是里斯本的招牌，1914 年通車，從 Martim Moniz 一路開到西邊的 Campo de Ourique，全程約 7 公里。它在七座山丘之間爬坡、急轉彎，穿過恩典區、阿法瑪老城、主教座堂、下城區和 Chiado，幾乎把里斯本最經典的街景一次串起來。想要有座位，記得在起點站上車。

叮叮兩聲，一台黃色的小電車從窄巷的轉角冒出來，車身離兩邊的牆只有一個手掌的距離，坐在窗邊的人幾乎可以伸手摸到人家門口的花盆。這就是里斯本最有名的 28 號電車。

里斯本為什麼到處都是電車？

里斯本又被叫做「七丘之城」，整座老城蓋在好幾座陡峭的山丘上，巷子又窄又彎，大型公車開不進去。小小一節、能爬陡坡又能急轉彎的電車，就成了最適合這座城市的交通工具。今天還在路上跑的黃色老電車，是整修過的「Remodelado」款，木頭座椅、黃銅把手，搭起來一路叮叮噹噹。

28 號電車會經過哪些地方？

28 號電車在 1914 年通車，路線從東邊的 Martim Moniz 廣場出發，往上爬進恩典區（Graça），接著穿過阿法瑪老城的太陽門觀景台（Portas do Sol），經過里斯本主教座堂，再下到龐巴爾式的下城區，然後一路往西爬上 Chiado、國會所在的 São Bento、Estrela 大教堂，最後停在 Campo de Ourique 的普拉澤雷斯墓園。全程大約 7 公里。

簡單說，里斯本最經典的幾個區域，它一次全部串起來。在太陽門觀景台下車，可以俯瞰阿法瑪紅色的屋頂一路滑到太加斯河；在主教座堂前，經常能拍到黃色電車從古老的石頭教堂前經過，是里斯本最有代表性的畫面。

坐 28 號電車有什麼技巧？

第一，在起點 Martim Moniz 上車。中途站幾乎都擠滿人，從起點排隊才有機會坐到窗邊的位置。第二，盡量早上或傍晚搭，避開中午觀光人潮最多的時段。第三，車上人擠人，背包轉到前面、手機收好，扒手很懂得挑這條路線。

如果嫌排隊太累，也可以反過來走：沿著電車路線步行，在彎道或陡坡上等它經過，拍照的角度反而更多。

Q&A常見問題

里斯本 28 號電車從哪裡上車？
建議在起點 Martim Moniz 上車，比較有機會坐到位置，中途站通常非常擁擠。
28 號電車會經過哪些景點？
會經過恩典區、阿法瑪的太陽門觀景台、里斯本主教座堂、下城區、Chiado、São Bento 與 Estrela，終點是 Campo de Ourique。
28 號電車是什麼時候開始營運的？
28 號電車在 1914 年通車，全程約 7 公里，目前由 Carris 營運。
坐 28 號電車要注意什麼？
車上擁擠，請把背包轉到前面、收好手機注意扒手，並盡量避開中午尖峰時段。
