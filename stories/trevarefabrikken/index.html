挪威 Trevarefabrikken：北極圈裡的靈魂工廠，桑拿、音樂與漁村的新日常

位於羅浮敦群島 Henningsvær 的 Trevarefabrikken，從老木工廠變成住宿、咖啡、音樂與活動共存的地方。這次來到建築後方的臨海桑拿屋，蒸著 80 幾度的熱石桑拿，接著跳進 0 度的海，再衝回桑拿，很熱血，也很慶幸我還活著！

位於挪威羅浮敦群島的 Henningsvær，有一座面海而立的老工廠，名叫 Trevarefabrikken。來到這裡，可以喝咖啡、吃點東西，也可以蒸桑拿、聽音樂，甚至住下來。我這次最期待的，是建築後方臨海岩岸上的桑拿屋。

80 幾度的桑拿，接著是 0 度的海

進入夏天的前夕，來到建築後方臨海岩岸的桑拿屋獨享一番，蒸著 80 幾度的熱石桑拿，我們還跳進 0 度的北極海，再衝回桑拿，很熱血也很慶幸我還活著！

桑拿屋的窗戶很大，坐在裡面就能看見海面和對岸的山。出去之後，眼前是高低不平的岩石，照片裡也看得到通往水邊的梯子。從屋內到海裡的距離很短，溫差卻很有感。

官網提供共用與包場兩種桑拿預約方式，不一定要住在這裡才能安排這項體驗。毛巾、泳衣要自己帶，現場另有冷水戶外淋浴。海水溫度會隨季節改變，0 度是我們這次下海時的體驗。

四個年輕人，接手一座老工廠

工廠建於 1948 年。2014 年，來自卑爾根的兩對兄弟到羅浮敦旅行，聽當地朋友說這棟建築正在出售，便湊錢買下。隔年，他們找來親友清理已關閉十年的工廠。

改造是一段一段完成的：先整理屋頂與外牆，做戶外酒吧，再開咖啡館、餐廳，接著增加客房。2017 年正式開門，也辦了第一屆 Trevarefest。當初來幫忙的木工朋友，後來也留在這個團隊裡。

工廠裡喝杯咖啡，也能住一晚

走進室內，長長的吧台、柱子、外露的管線和窗邊的座位，把原來工廠的尺度留了下來。桌上是咖啡、麵包和甜點，窗外還是羅浮敦的海。

如果想住下來，官網介紹的客房保留了工廠原有細節，使用回收磚、梣木地板與大面積工業窗。這次我沒有拍到客房，不過從公共空間就能看見，新用途和舊建築是放在一起使用的。

戶外的 Steinbruddet Pizza 供應窯烤披薩，披薩窯還用了工廠原煙囪的回收磚。坐在外面的長桌旁，可以同時看海與山。餐飲營業時間會調整，行前可查官網。

地方創生，從讓人願意聚在這裡開始

我喜歡這裡有很多種留下來的理由。旅人可以來蒸桑拿、吃東西，居民也能來喝一杯、參加活動；不用每個人都住進旅館，才和這棟工廠有關係。

官網的活動表裡，有音樂演出、桌遊夜、二手市集、快閃餐飲、知識問答和派對。瑜伽則有每週課程、工作坊與季節性的靜修活動。場地也曾用來辦創作工作坊、藝術工作室、聚餐與小型會議，白天和夜晚可以有完全不同的使用方式。

這樣的擾動很具體：老工廠多了工作機會，原本只來旅行的人留下來做事，居民多了可以見面和辦活動的場所。活動也不只排在夏天。對一個漁村來說，咖啡館平日有沒有開、淡季還有沒有節目，都會影響這個地方能不能持續有人使用。

當然，一座工廠的改造不能代表整個漁村的發展。但在這裡，能看見住宿、餐飲和文化活動怎麼一起運作，也能看見建築修繕一直在進行。比起只看改造前後的照片，我更想知道的是，這些空間接下來還會被拿來做什麼。

去有風的地方！

同在 Henningsvær 一帶，也可以看看羅浮敦鱈魚乾與漁村的曬魚架。

Q&A常見問題

Trevarefabrikken 可以住嗎？
可以，工廠內設有客房，也有咖啡、餐飲與活動空間。
沒有住宿可以預約桑拿嗎？
可以，官網提供共用場次與包場預約，請自備毛巾、泳衣。
Trevarefabrikken 有哪些活動？
活動表可見音樂演出、市集、桌遊、快閃餐飲、問答與派對，另有瑜伽課程和工作坊，實際安排以官網為準。
